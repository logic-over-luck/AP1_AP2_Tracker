- Einfach verkettete Liste: Jeder Knoten hält einen Wert und einen Verweis auf den nächsten, der Kopf zeigt auf den ersten; Einfügen heißt Verweise umhängen, eine Position erreicht man nur durch Durchlaufen ab dem Anfang. _(buch:FS2-2.2.1)_

_Hinweis:_ Das Lehrbuch (FS2 2.2.1) nennt bei der verketteten Liste „geringen Speicherplatzbedarf“ und bei der Hashtabelle „weniger Speicher als Arrays“; richtig ist: Je Element braucht eine Liste mehr Speicher als ein Array (Wert plus Verweis), sparsamer ist sie nur, weil nichts auf Vorrat angelegt wird; eine Hashtabelle braucht in der Regel mehr Speicher als ein Array mit denselben Werten.
