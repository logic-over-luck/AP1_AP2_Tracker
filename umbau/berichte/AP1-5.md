- Aufbau einer Virtual Desktop Infrastructure: Jeder Desktop läuft als virtuelle Maschine auf einem Server, ein Connection Broker verbindet den Benutzer über Client-Software oder Browser mit seiner VM, und weil die Sitzung auf dem Server läuft, bleibt sie bei einem Abbruch der Verbindung erhalten. _(buch:GS-2.7.3)_
